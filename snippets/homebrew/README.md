# Homebrew update/upgrade

&larr; [back to snippet collection](./../../README.md)

## Description

This snippet adds an alias command for `brew update && brew upgrade` as a shortcut.

## Requirements

 - ensure [Homebrew](https://brew.sh/) is installed on your MacOS

##  Usage

It's as easy as typing `brup` into your terminal.

```bash
brup
# that's it, Homebrew will be updated and all dependencies will be upgraded
```
